# LangChain Workbooks

Self-learning workbooks with theory, diagrams, quizzes, code snippets, and complete hands-on instructions using uv. Learners create and run their projects in their own workspace.

## Study order

1. [LangChain Learning Workbook](01-learning-workbook/README.md) — learn the concepts and practice individual skills.
2. [RAG Capstone Workbook](02-rag-capstone-workbook/README.md) — Draft: a guided offline permission-aware RAG build (W-RAG-00 to W-RAG-13) with an independent transfer brief; no live-model or deployment evidence.

## Workbook style

Both workbooks follow the [study guide style](../../docs/study-guide-style.md), extended with setup commands, filename-labeled code snippets, expected output, verification checkpoints, and troubleshooting.

The learning workbook is **Draft** and contains substantive chapters, builds and self-study assessments. Its README records historical verification and remaining limitations. The [RAG module capstone](02-rag-capstone-workbook/README.md) is **Draft** with a verified offline guided reference and independent transfer brief; live-model quality and deployment remain unverified. No workbook is declared Ready for pilot or Published; see the [status review](../../docs/content-status-review.md).

The standalone guide is a Draft reference route. `part1-langchain-demo` and `part2-fernwood-assistant` are reference-only, excluded from course implementation, verification and completion requirements.
