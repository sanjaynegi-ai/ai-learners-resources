# W-LC source record

> **Scope:** every external link in W-LC-00 to W-LC-18 · **Access checked:** 2026-10-15 · **Record:** R03

Every link in the chapters is **Reference**: optional lookup material. Each chapter explains what you need to complete its tasks, and its acceptance criteria do not depend on reading these pages. Installer and provider pages are marked **Reference (setup fallback)**; you need them only if the chapter's setup commands fail or you choose that route. No link is Required, Recommended or Deep dive.

**What "checked" means:** on 2026-10-15 each page answered an HTTP request, and pages that now redirect are noted. Opening a page does not confirm that its current content matches the API versions pinned in the workbook. Those versions are in each project's lockfile, and [lesson-contract.md](lesson-contract.md) records which routes were executed. Documentation is free to read; using a hosted model, tracing service or vector store can cost money, as each chapter's cost note explains.
